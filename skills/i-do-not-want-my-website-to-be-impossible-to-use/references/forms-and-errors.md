# Forms & Errors

Inspect labels, instructions, required state, autocomplete, validation, error
association and recovery.

## Checks
- `A11Y-FORM-001` HIGH/MEDIUM: input lacks a programmatically associated label.
- `A11Y-FORM-002` MEDIUM: error is color-only or not associated with the field.
- `A11Y-FORM-003` MEDIUM: validation failure does not provide actionable
  recovery.
- `A11Y-FORM-004` LOW/MEDIUM: relevant autocomplete/input purpose is incorrect.
- `A11Y-FORM-005` MEDIUM: placeholder is the only label.

Test both successful submission and failure recovery.
