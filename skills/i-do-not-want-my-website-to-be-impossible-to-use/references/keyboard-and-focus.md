# Keyboard & Focus

When runtime access exists, complete critical journeys using keyboard alone.

Check:
- reachability/operability;
- logical focus order;
- visible focus;
- keyboard traps;
- dialog focus entry/return;
- focus after route/content changes;
- repeated-navigation bypass where relevant.

## Checks
- `A11Y-KBD-001` HIGH: critical action cannot be completed by keyboard.
- `A11Y-KBD-002` HIGH: keyboard trap.
- `A11Y-FOCUS-001` MEDIUM: focus indicator absent/obscured.
- `A11Y-FOCUS-002` MEDIUM: modal/overlay focus is lost or restored incorrectly.
- `A11Y-ORDER-001` MEDIUM: DOM/focus order materially conflicts with task order.
