# WIP-190–WIP-196 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete WIP-190, WIP-191, WIP-192, WIP-193, and WIP-196 sequentially with evidence-bounded validation, one atomic implementation commit per issue, and accurate Linear transitions.

**Architecture:** Add small Ruby validation modules for repository structure, fixture integrity, deterministic hashing, and launch-kit integrity; add a narrowly scoped Ajv 2020 tool for the machine-readable report contract; keep the broken Next.js fixture inert; record Codex behavior as observed evidence rather than inferred capability. The approved design at `docs/superpowers/specs/2026-09-12-wip-190-196-design.md` is binding.

**Tech Stack:** Ruby standard library, Minitest, GitHub Actions, Next.js App Router fixture syntax, YAML, JSON Schema Draft 2020-12, Node.js, Ajv 8.17.1, Codex CLI, Linear MCP.
