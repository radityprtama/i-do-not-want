# Short post

Your AI can build a SaaS in minutes. Can it prove the admin API checks permissions,
the testimonial is real, analytics waits for consent, and payment retries will not
charge twice?

`i-do-not-want` is a collection of six evidence-driven pre-ship Agent Skills. Its one
rule is simple: never call something PASS without evidence.

```bash
npx skills add radityprtama/i-do-not-want
```

GitHub: https://github.com/radityprtama/i-do-not-want

skills.sh: https://skills.sh/radityprtama/i-do-not-want/i-do-not-want

The repository includes an intentionally broken Next.js fixture, stable expected
findings, deterministic validation, and a versioned JSON report contract. It does not
replace legal counsel or a professional security or accessibility assessment.

Try it on a fixture and send false positives, missed findings, fixture contributions,
or behavioral compatibility reports from other agents.
