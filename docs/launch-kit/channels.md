# Channel Checklist

This is a preparation checklist, not a publication record. No channel has been posted
to as part of WIP-196.

## Rules for every channel

Before posting:

- read and comply with the current community self-promotion rules;
- do not post if project sharing is prohibited;
- tailor the explanation to the community instead of duplicating submissions;
- disclose project affiliation where appropriate;
- avoid repetitive posts, unsolicited direct messages, and cross-community spam;
- never manufacture votes, comments, stars, installs, or testimonials;
- answer criticism with evidence and record useful false positives or missed findings.
