# Security Policy

This project contains audit instructions. It is not a vulnerability scanner and
does not guarantee that a reviewed application is secure.

## Reporting a vulnerability in this repository

If disclosure could create harm, report the issue privately to the repository
maintainers instead of opening a public issue.

## Findings produced by the skills

When auditing another project:
- follow that project's disclosure policy;
- never publish credentials, tokens, personal data or exploitable details just
  to demonstrate a finding;
- redact secret values in reports;
- prefer minimal proof over destructive exploitation.
